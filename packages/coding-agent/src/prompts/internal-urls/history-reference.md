`history://current/entry/<id>?session=<sid>&leaf=<id>&before=N&after=N` reads an entry of your own session with the entries around it, including entries before a compaction. `session` checks the current session id; `leaf` selects a branch endpoint (default: current leaf). `before` and `after` default to 6 each and are capped at 50. Follow the `Earlier:` and `Later:` URLs to navigate.
